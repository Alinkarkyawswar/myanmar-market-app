မြန်မာ့ဈေးကွက် Android Starter (အခမဲ့)

ဖိုင်များ
- index.html: App interface
- manifest.webmanifest: installable web app metadata
- sw.js: offline cache
- icon.svg: app icon

အရေးကြီး:
ဒီ project သည် Android Chrome တွင် install လုပ်နိုင်သော PWA starter ဖြစ်ပြီး native APK မဟုတ်ပါ။
ဖုန်းထဲတွင် file:// ဖြင့်ဖွင့်လျှင် install/offline လုပ်ဆောင်ချက်များ အပြည့်အဝ မရနိုင်ပါ။
Install လုပ်ရန် HTTPS hosting လိုအပ်သည်။ အခမဲ့စမ်းသပ်ရန် GitHub Pages ကဲ့သို့ static hosting တွင် ဖိုင်အားလုံးကိုတင်ပါ။
စာရင်းများသည် browser localStorage ထဲတွင်သာသိမ်းထားပြီး အခြားဖုန်းများနှင့် မမျှဝေနိုင်သေးပါ။ Shared database, authentication, moderation, privacy policy နှင့် payment စနစ်များ မပါသေးပါ။
ဖုန်းနံပါတ်နမူနာများသည် demo အတွက်သာဖြစ်ပြီး အမှန်တကယ်ဝန်ဆောင်မှုပေးသူများ မဟုတ်ပါ။
